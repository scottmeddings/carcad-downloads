# CarCad downloads

Public installers and release notes for CarCad. This repository contains no application source code.

- Latest release: [Releases](https://github.com/scottmeddings/carcad-downloads/releases/latest)
- Machine-readable latest version: [`latest.json`](latest.json)
- Release notes and SHA-256 checksums: [`releases/`](releases/)

Installers are attached to each GitHub Release, not committed to the repository. Verify downloads against `SHA256SUMS.txt`.
